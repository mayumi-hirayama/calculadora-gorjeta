# 🧾 Calculadora de Gorjeta

Calculadora web desenvolvida em HTML, CSS e JavaScript puro.

## Funcionalidades
- Calcula o valor da gorjeta com base na porcentagem escolhida
- Calcula o total da conta com gorjeta
- Divide o valor entre N pessoas

## Tecnologias
- HTML
- CSS
- JavaScript

## Como usar
Baixe o arquivo `calculadora_gorjeta.html` e abra no navegador.
